A clean, low-variance paper-trading bot for the Pump.fun Sharpe Sprint. It only enters bonding curves that survived the launch burst, show sustained buy pressure from several distinct wallets over both a short and a long lookback, and sit near their highs without having already run away — then it risks a tiny first ticket, adds only while the move keeps working, and exits fast on a stop loss, trailing stop, fading inflow, a big single dump, or a hard time limit. Steady small gains beat wild PnL swings, so the bot would rather miss a runner than ride a dump. Minimum-size probe round trips keep the run above the 20-distinct-coin guardrail without adding variance.

node main.ts
